# client

React 19 frontend built with Vite. Bundled into the server JAR at build time — not deployed separately.

## Quick start

```bash
npm install
npm run dev   # dev server at http://localhost:5173 (proxies API to localhost:9753)
```

## Tests

```bash
npm test              # watch mode
npm run test:run      # single run
npm run test:coverage # with coverage report
```
