# client

React 19 frontend built with Vite. Bundled into the server JAR at build time — not deployed separately.

## Quick start

```bash
make dev   # dev server at http://localhost:5173 (proxies API to localhost:9753)
```

## Tests

```bash
make test    # single run with coverage report
```
